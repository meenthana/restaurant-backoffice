# ระบบสั่งอาหารด้วยตนเองและจัดการงานครัว สำหรับร้านอาหารตามสั่งขนาดเล็ก (V3)

Self-Service Ordering and Kitchen Management System for Small Made-to-Order Restaurants

โครงงานวิทยาการคอมพิวเตอร์ คณะศิลปศาสตร์และวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ พ.ศ. 2569
ผู้จัดทำ นายธนา ศรีศรทอง (6521650424) · อาจารย์ที่ปรึกษา อาจารย์ปรวี วงศ์สวัสดิ์สุริยะ

เว็บทดลองใช้งาน: https://thanas.freehosting.dev/restaurant-backoffice/
- ตู้สั่งอาหาร: `/kiosk/`
- สั่งล่วงหน้าออนไลน์ (LINE Login): `/online/`
- หลังร้าน: `/login.php`

## ภาพรวม

ทุกช่องทางเป็นแบบจ่ายก่อน: ลูกค้าสั่งและชำระเงิน → ระบบยืนยันยอด → ใบงานเข้าครัว → ครัวทำเสร็จ → แคชเชียร์ส่งมอบโดยตรวจรหัสบัตร → บัตรว่างพร้อมใช้รอบต่อไป

| ส่วน | หน้าที่ |
|---|---|
| ตู้สั่งอาหาร (kiosk) | เลือกเมนู ตัวเลือกเสริม หมายเหตุรายจาน สั่งด้วยเสียงภาษาไทย ตรวจเบอร์สมาชิก จ่ายด้วย QR หรือเลือกจ่ายเงินสดที่เคาน์เตอร์ รับบัตรคิว |
| สั่งออนไลน์ | เข้าสู่ระบบด้วย LINE ใช้สถานะสมาชิกแทนบัตร จ่ายด้วย QR เท่านั้น เลือกเวลารับ |
| แคชเชียร์ (POS) | รับเงินสด สั่งเมนูทำเอง (DIY: ฐาน 40 บาท เลือกเนื้อสัตว์ได้หลายอย่าง +10 บาทต่ออย่าง) ส่งมอบอาหารพร้อมตรวจรหัสบัตร |
| ครัว | จอใบงานเรียงตามลำดับ สั่งงานด้วยเสียง จอเรียกคิว |
| หลังร้าน | เมนู กลุ่มตัวเลือกเสริม สูตรและวัตถุดิบ สต๊อก สมาชิกและแต้ม บัตรคิวสองประเภท (ตู้/เคาน์เตอร์) รายงานรายได้ ผู้ใช้ 5 บทบาท บันทึกการทำงาน |

การชำระเงิน QR ใช้ Omise (PromptPay) หรือ SCB Open API ระบบรับผลผ่าน webhook และตรวจซ้ำกับผู้ให้บริการก่อนยืนยันยอด

## เทคโนโลยี

PHP 8.1+ (PDO), MariaDB 10.4+ / MySQL 8, Bootstrap 5, JavaScript ล้วน, Web Speech API (th-TH)

## โครงสร้างโฟลเดอร์

ดูรายละเอียดทุกไฟล์ได้ที่ [CODE_MAP.md](CODE_MAP.md)

| โฟลเดอร์ | คืออะไร |
|---|---|
| `kiosk/` | ตู้สั่งอาหาร จอคิว หน้าติดตามสถานะ |
| `online/` | หน้าสั่งออนไลน์และ LINE Login |
| `modules/` | หน้าหลังร้าน แยกตามเมนู |
| `classes/` | ตรรกะหลัก เช่น `KioskOrder`, `VoiceOrderParser`, `OmiseGateway` |
| `api/` | จุดเรียกจาก JavaScript และ webhook ของ Omise/SCB |
| `config/` | การตั้งค่า (ค่าลับอยู่ใน `config/private.php` ซึ่งไม่อยู่ใน repository) |
| `sql/` | สคริปต์สร้างและอัปเดตฐานข้อมูล |
| `tests/` | ชุดทดสอบการแยกคำสั่งเสียง |

## การติดตั้ง

1. วางโฟลเดอร์ไว้ที่ `htdocs/restaurant-backoffice`
2. สร้างฐานข้อมูล แล้ว Import ตามลำดับ
   1. `sql/install_hosting.sql`
   2. `sql/migration_v2_13_point_redeem.sql`
   3. `sql/migration_v3_0_counter_diy.sql`
3. คัดลอก `config/private.example.php` เป็น `config/private.php` แล้วกรอกค่าฐานข้อมูล LINE และช่องทางชำระเงิน
4. เปิด `/restaurant-backoffice/setup.php` เพื่อสร้างบัญชีเจ้าของร้านคนแรก แล้วนำ `setup.php` ออกจากเซิร์ฟเวอร์จริง

ถ้าไม่เปิด Omise/SCB ตู้จะรับเฉพาะเงินสดที่เคาน์เตอร์

## การทดสอบ

วัดความแม่นยำการแยกคำสั่งเสียง (ต้อง Import `tests/voice_seed_menu.sql` เข้าฐานข้อมูลทดสอบก่อน)

```
php tests/voice_eval.php            # ชุดพัฒนา 50 ประโยค
php tests/voice_eval.php --holdout  # ชุดทดสอบแยก 30 ประโยค
```

ผลล่าสุด: ชุดพัฒนาถูกทั้งประโยค 49/50 (98.0%) ชุดทดสอบแยก 27/30 (90.0%)

## สิ่งที่ไม่ได้อยู่ใน repository

`config/private.php` (รหัสผ่านฐานข้อมูลและคีย์ LINE/Omise/SCB), ไฟล์สำรองข้อมูล และสลิปที่ลูกค้าอัปโหลด
