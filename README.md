# ระบบบริหารจัดการร้านอาหารและ POS V2

ระบบเว็บ PHP สำหรับร้านอาหาร ครอบคลุมหน้าร้าน ผังโต๊ะ คิว การจอง ออเดอร์ ครัว การคิดเงิน สต๊อก สมาชิก และรายงาน โดยคงแนว UI ของเวอร์ชันเดิมไว้

## ความต้องการของระบบ

- PHP 8.1 ขึ้นไป (แนะนำ PHP 8.2 ของ XAMPP)
- MariaDB 10.4 ขึ้นไป หรือ MySQL 8 ขึ้นไป
- เปิดส่วนขยาย PHP: PDO MySQL, cURL และ mbstring
- Apache และ URL โครงการเป็น `/restaurant-backoffice/`

## วิธีติดตั้งใหม่

1. แตกไฟล์และตั้งชื่อโฟลเดอร์เป็น `restaurant-backoffice`
2. วางไว้ที่ `F:\xampp\htdocs\restaurant-backoffice` หรือโฟลเดอร์ `htdocs` ของเครื่อง
3. เปิด phpMyAdmin และ Import ไฟล์ `sql/install_v2_full.sql` เพียงไฟล์เดียว
4. เปิด `http://localhost/restaurant-backoffice/setup.php`
5. สร้างบัญชีเจ้าของร้านคนแรก แล้วเข้าสู่ระบบ
6. หลังสร้างบัญชีสำเร็จ ควรนำ `setup.php` ออกจากเซิร์ฟเวอร์จริง

## วิธีอัปเดตจากฐานข้อมูลเวอร์ชันเดิม

1. สำรองฐานข้อมูล `restaurant_backoffice`
2. แทนที่ไฟล์เว็บด้วยเวอร์ชัน V2
3. ถ้าเป็นฐานข้อมูล V1 ให้ Import `sql/migration_v2_complete.sql`, `sql/migration_v2_1_tables.sql` และ `sql/migration_v2_2_members.sql` ตามลำดับ
4. ถ้าอัปเดตจาก V2.1 ให้ Importเฉพาะ `sql/migration_v2_2_members.sql` เพียงหนึ่งครั้ง
5. เข้าสู่ระบบและตรวจหน้าแดชบอร์ด ผังโต๊ะ ครัว คิว และการจอง

ไฟล์ Migration จะไม่ลบออเดอร์เดิม และจะย้ายข้อมูลการชำระเดิมเข้าสู่ตาราง `payments` รวมถึงสร้างใบงานครัวให้ออเดอร์ที่ยังเปิดอยู่

## ขั้นตอนการทำงานหลัก

### ลูกค้าทานที่ร้าน

ผังโต๊ะ → เปิดโต๊ะเดี่ยวหรือโต๊ะรวม → รับออเดอร์ → ใบงานเข้าครัว → ระหว่างใช้งานสามารถรวมโต๊ะ ย้ายโต๊ะ คืนโต๊ะ สั่งเพิ่ม หรือคิดเงิน → ชำระเงินท้ายมื้อ → พิมพ์ใบเสร็จ → รอทำความสะอาด → โต๊ะว่าง เจ้าของร้านและผู้จัดการเพิ่มหรือลบโต๊ะจากหน้าเดียวกันได้

### คิวรอโต๊ะ

เพิ่มคิว → ออกหมายเลข → เรียกคิว → เลือกโต๊ะหนึ่งตัวหรือหลายตัว → เปิดบัญชีโต๊ะ → รับออเดอร์

### การจองโต๊ะ

สร้างการจอง → ยืนยัน → ลูกค้าเช็กอิน → พนักงานเลือกโต๊ะ → เปิดบัญชีโต๊ะ → รับออเดอร์

### สั่งออนไลน์รับกลับบ้าน

เข้าสู่ระบบ LINE หรือโหมดสาธิต → เลือกเวลารับ → เลือกเมนู → ชำระแบบจำลอง → ครัวเริ่มทำ → อาหารพร้อม → ลูกค้ารับอาหาร → ปิดออเดอร์

## หน้าเว็บที่มีใน V2

- `modules/dashboard/` ภาพรวมร้าน รายได้ งานครัว คิว และสต๊อก
- `modules/tables/` ผังโต๊ะ โต๊ะรวม และทำความสะอาด
- `modules/queue/` คิวรอโต๊ะ
- `modules/reservations/` การจองและเช็กอิน
- `modules/orders/` รับและติดตามออเดอร์
- `modules/kitchen/` หน้าจอครัวแยกตามรอบที่สั่ง
- `modules/pos/` รับชำระและใบเสร็จ
- `modules/receipts/` ประวัติใบเสร็จ แยกหน้าร้าน/ออนไลน์ และดูแบบรายวัน/รายเดือน
- `modules/refunds/` ขอ อนุมัติ และบันทึกคืนเงิน
- `modules/menu/` เมนู สูตรอาหาร และตัวเลือกเสริม
- `modules/stock/` รับเข้า ตัดแบบ FEFO แปรรูป และของเสีย
- `modules/members/` สมาชิก LINE ข้อมูลติดต่อ คะแนนสะสม ประวัติแต้ม และการระงับสิทธิ์
- `modules/revenue/` รายงานรายได้ กำไร และความผิดปกติ
- `modules/users/` บัญชีและบทบาทพนักงาน
- `modules/settings/` ข้อมูลร้านและกฎเวลา
- `online/` สั่งกลับบ้าน จองโต๊ะ และติดตามสถานะสำหรับลูกค้า

## การตั้งค่า LINE อย่างปลอดภัย

ไฟล์ ZIP นี้ไม่มี Channel Secret หรือ Access Token จริง ให้ตั้งค่า Environment Variables ต่อไปนี้ใน Apache:

```text
LINE_API_ENABLED=true
LINE_LOGIN_CHANNEL_ID=...
LINE_LOGIN_CHANNEL_SECRET=...
LINE_LOGIN_REDIRECT_URI=https://YOUR-DOMAIN/restaurant-backoffice/online/callback.php
LINE_MESSAGING_CHANNEL_ACCESS_TOKEN=...
```

ถ้ายังไม่ตั้งค่า LINE ระบบจะแสดงปุ่ม “เข้าสู่ระบบสาธิต” เพื่อใช้ทดสอบโครงงานบน localhost

หากเคยใส่ Secret หรือ Token ลงใน ZIP/โค้ดเวอร์ชันเก่า ควรออกค่าใหม่ใน LINE Developers Console ก่อนนำระบบขึ้นใช้งานจริง

## การตั้งค่าฐานข้อมูลด้วย Environment Variables (ไม่บังคับ)

```text
RESTAURANT_DB_HOST=localhost
RESTAURANT_DB_NAME=restaurant_backoffice
RESTAURANT_DB_USER=root
RESTAURANT_DB_PASS=
```

หากไม่ตั้งค่า ระบบจะใช้ค่ามาตรฐาน XAMPP คือ `localhost`, ฐานข้อมูล `restaurant_backoffice`, ผู้ใช้ `root` และรหัสผ่านว่าง

## หมายเหตุการใช้งานจริง

- การชำระออนไลน์เป็นระบบจำลอง ไม่ได้ตัดเงินจริง
- การคืนเงินในระบบเป็นการบันทึกการอนุมัติและรายการบัญชี ต้องดำเนินการคืนเงินจริงผ่านธนาคารแยกต่างหาก
- ควรเปิด HTTPS เมื่อต่อ LINE จริง
- ควรสำรองฐานข้อมูลก่อน Import Migration ทุกครั้ง
