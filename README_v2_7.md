# อัปเดต v2.7 — ตู้สั่งอาหารด้วยตนเอง (Self-Service) + ตรวจสลิป + สั่งด้วยเสียง

## ขั้นตอนหลังวางไฟล์ (ทำครั้งเดียว)

1. **รัน SQL** — phpMyAdmin → เลือกฐานข้อมูล `restaurant_backoffice` → แท็บ SQL → วางไฟล์
   `sql/migration_v2_7_selfservice.sql` ทั้งไฟล์ → Go
   (รันซ้ำได้ ไม่ทำข้อมูลเดิมหาย ถ้ายังไม่เคยรัน v2.6 ให้รัน `migration_v2_6_reorder_point.sql` ก่อน)
2. **ตั้งเบอร์พร้อมเพย์** — หลังร้าน → จัดการ → ตั้งค่าร้าน → "เบอร์พร้อมเพย์ของร้าน"
   (ถ้าไม่ใส่ ตู้จะรับได้เฉพาะเงินสด)
3. **เปิดตู้** — บนแท็บเล็ตเปิด `http://<ที่อยู่เครื่อง>/restaurant-backoffice/kiosk/`
   หรือจากหลังร้าน → จัดการ → "เปิดหน้าตู้สั่งอาหาร"

## ภาพรวม: จ่ายก่อน แล้วครัวค่อยทำ (แบบ KFC)

```
ลูกค้าที่ตู้                          แคชเชียร์ / ครัว
─────────────                         ─────────────────
เลือก ทานที่ร้าน / กลับบ้าน
เลือกเมนู (แตะ หรือ พูด)
เลือกวิธีจ่าย ──┬─ เงินสด ──→ ได้เลขคิว K001 ──→ แคชเชียร์กด "รับเงิน" ─┐
               └─ พร้อมเพย์ → สแกนจ่าย + ส่งสลิปจากมือถือ ─ ตรวจผ่าน ──┤
                                                                     ▼
                                                        ออเดอร์เข้าครัวอัตโนมัติ
                                                        ครัว: เริ่มทำ → เสร็จ → ส่งมอบ
                                                        ปิดออเดอร์ + ตัดสต๊อก FEFO
```

**ทำไมไม่ส่งเข้าครัวทันทีตอนกดสั่ง** ถ้าลูกค้าเลือกเงินสดแล้วเดินออกไปไม่จ่าย ครัวจะทำอาหารทิ้ง
ระบบจึงรอให้ยืนยันการจ่ายก่อน และยกเลิกออเดอร์ที่ค้างจ่ายเกิน 30 นาทีให้เอง (ตั้งได้)

**ปัญหาเงินสดบนตู้** แก้แบบเดียวกับ KFC / McDonald's คือตู้ไม่รับเงินสดเอง
ลูกค้าได้เลขคิวแล้วไปจ่ายที่เคาน์เตอร์ ร้านไม่ต้องซื้อเครื่องรับเงินอัตโนมัติ

## หลักการที่ใช้ (ไว้ตอบอาจารย์)

| ส่วน | หลักการ | ผล |
|---|---|---|
| เลขคิวรายวัน | `SELECT MAX(queue_no)+1 ... FOR UPDATE` ใน Transaction | แท็บเล็ตหลายเครื่องกดพร้อมกันก็ไม่ได้เลขซ้ำ |
| QR พร้อมเพย์ | มาตรฐาน **EMVCo / Thai QR Payment** (Tag-Length-Value + **CRC-16/CCITT**) | สร้าง QR ที่ฝังยอดเงินเองได้ ไม่ต้องพึ่ง API ไม่เสียเงิน |
| ส่งสลิปจากมือถือ | **Capability Token** 128 บิต (`random_bytes(16)`) + `hash_equals` | ไม่ต้องล็อกอิน แต่คนอื่นเดาลิงก์ออเดอร์ไม่ได้ |
| ออเดอร์เข้าครัว | Event หลัง `Payment::record` ("จ่ายครบ → สร้างใบงานครัว") | ทุกช่องทางจ่าย (สด/สลิป/พนักงานอนุมัติ) ใช้กฎเดียวกัน |
| ค้างจ่าย | **Lazy Expiration** เช็กตอนเปิดหน้าคิดเงิน | ไม่ต้องใช้ cron |
| ตู้สาธารณะ | **Server-side validation** ราคา/ของหมด/Add-on/จำนวน | แก้ข้อมูลในเบราว์เซอร์ก็สั่งราคาผิดไม่ได้ |
| คนเดินหนี | **Idle timeout** 90 วินาที → ถาม 15 วินาที → ล้างตะกร้า | ลูกค้าคนถัดไปไม่เห็นรายการคนก่อน |
| ตรวจสลิป | ตรวจ 5 ชั้น + `trans_ref` UNIQUE | กันสลิปซ้ำ/ยอดไม่ตรง/สลิปเก่า |
| สั่งด้วยเสียง | Web Speech API + **Character Bigram Similarity** | "กะเพราหมูสองจาน ไข่ดาวด้วย" → รายการในตะกร้า |

## ข้อควรระวังวันสอบ

- **QR ส่งสลิปบนตู้ต้องเปิดจากมือถือได้** ถ้าตู้เปิดผ่าน `localhost` ลิงก์ใน QR จะเป็น `localhost` ซึ่งมือถือเปิดไม่ได้
  → เปิดตู้ผ่าน **Cloudflare Tunnel** (ลิงก์ https) หรือ IP ของเครื่องในวง Wi-Fi เดียวกัน
- **สั่งด้วยเสียงต้องใช้ https หรือ localhost** และใช้ได้กับ Chrome / Edge เท่านั้น
  → ใช้ Cloudflare Tunnel ก็ได้ทั้งสองอย่าง
- หน้าเว็บโหลด Bootstrap / ไอคอน / ตัวสร้าง QR จาก CDN จึงต้องต่ออินเทอร์เน็ต
